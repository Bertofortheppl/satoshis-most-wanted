# Satoshi's Most Wanted

> The sheriff's wall for sats-paying dev work: every verified opportunity,
> badged with honest signal, free for the whole town.

A free, open-data aggregator of Lightning/Bitcoin-paying developer
opportunities — bounties, PR rewards, negotiated programs — across platforms,
with a verification layer nobody else provides: escrow status, contested
crowding, repo freshness, rewarder trust. No accounts, no escrow, no take-rate.
Tips keep the lights on.
